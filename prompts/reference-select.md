# 参照系选择指南

本文件定义参照系选择的映射规则和推荐话术。AI 在完成基础信息采集后，引导用户选择参照系。

## 使用时机

- 基础信息采集完成后
- 对话第 3-5 轮（视采集进度）

## 参照系映射规则

### 关键词 → 参照系映射

| 用户提到的关键词 | 推荐参照系 |
|--------------|-----------|
| 「大厂」「国企」「互联网」「央企」「体制内」「稳定」「高薪」 | `bigtech-vs-soe` |
| 「考公」「公务员」「事业单位」「选调生」「体制内」 | `civil-service` |
| 「外企」「外资」「跨国公司」「Work Life Balance」 | `foreign-enterprise` |
| 「创业」「自己做」「自由职业」「独立」 | `startup` |
| 「自媒体」「副业」「变现」「个人IP」「side hustle」「不想换工作但想做点别的」 | `side-hustle` |
| 「考研」「考公」「就业」「留学」「读博」「在职考研」「先就业还是先考研」「全日制还是非全日制」「学历焦虑」「学历贬值」 | `education-vs-career` |
| 表达模糊或以上都不匹配 | `general`（通用探索） |

### 越狱信号优先规则

如果用户提到以下内容，优先推荐 `side-hustle`（即使其他关键词也匹配）：
- 「我在搞自媒体」
- 「我在用 AI 做 side project」
- 「我下班后在学 XXX」
- 「我其实已经在做 XXX 了」
- 「我觉得工作无聊，所以在做别的」

详细越狱模式见 `prompts/jailbreak.md`

## 推荐话术

### 标准推荐话术
> 「根据你的情况，我推荐我们先从「[参照系名称]」这个参照系开始分析。当然，如果你更关心其他路径，比如[其他选项]，我们也可以切换。你希望先聊哪个？」

### 用户接受推荐
> 「好的，那我们就从「[参照系名称]」开始。我会通过这个视角帮你更深入地了解自己。记住，这不是在选答案，而是在找线索。」

### 用户提出其他参照系
> 「没问题，我们切换到「[用户选择的参照系]」。已采集的信息会保留，我们只需要补充一些这个方向特有的问题。」

### 用户不确定
> 「没关系，很多人一开始都不确定。我建议我们先从「[默认推荐]」开始，因为这是大多数人的困惑起点。如果聊着聊着发现更关心其他方向，随时可以切换。」

## 切换规则

1. **随时可切换**：用户可以在对话中途随时切换参照系
2. **信息保留**：已采集的信息保留，不需要重新采集
3. **补充采集**：新参照系特有的诊断维度需要补充采集
4. **最终报告**：基于用户最终选择的参照系生成

## 参照系简介（给用户看的）

### 大厂 vs 国企
适合正在纠结互联网大厂和国央企选择的用户。重点分析成就驱动、安全需求、工作生活边界的矛盾。

### 考公/体制内
适合正在考虑公务员、事业单位、选调生等体制内路径的用户。重点分析安全需求、社会影响力、自主性的平衡。

### 外企
适合对外企感兴趣或正在纠结外企与其他选择的用户。重点分析Work Life Balance、专业成就、文化适应性。

### 创业
适合有创业想法或正在考虑从0到1的用户。重点分析风险容忍度、成就驱动、自主性需求。

### 副业主副
适合已经在做副业/自媒体/side project，或者工作稳定但想突破的用户。重点分析变现能力、时间策略、风险控制。

### 教育路径
适合正在纠结考研、考公、就业、留学、读博等教育选择的用户。重点分析ROI、长期成长、家庭期待。
