# 越狱信号识别指南

本文件定义「越狱模式」的触发条件和诊断策略。当用户已经在做副业/自媒体/side project 时，诊断焦点从「选哪个平台」转向「卡在哪道门」。

## 使用时机

- 用户在对话中提到已经在做副业/自媒体/side project
- 在基础信息采集阶段或参照系选择阶段识别到越狱信号

## 越狱信号清单

### 强信号（立即触发越狱模式）
- 「我在搞自媒体」
- 「我在用 AI 做 side project」
- 「我下班后在学 XXX」
- 「我其实已经在做 XXX 了」
- 「我觉得工作无聊，所以在做别的」

### 弱信号（需进一步确认）
- 「我对 XXX 很感兴趣」（可能是想象，不是行动）
- 「我朋友在做 XXX」（可能是观察者，不是参与者）
- 「我了解过 XXX」（可能是研究，不是实践）

### 确认话术（针对弱信号）
> 「你提到对 XXX 感兴趣，是已经在做了，还是停留在想法阶段？如果已经在做，能跟我聊聊进展吗？」

## 越狱模式诊断策略

### 诊断焦点转变

| 常规模式 | 越狱模式 |
|---------|---------|
| 选哪个平台 | 已经在越狱了，但卡在哪道门 |
| 职业选择能力 | 副业变现能力 |
| 大厂 vs 国企 | 主业稳定 + 副业突破 |

### 核心诊断问题

1. **能力验证**
   - 「你的副业已经证明了什么能力？」
   - 「这些能力在市场上值多少钱？」

2. **变现卡点**
   - 「你卡在哪一步了？是涨粉、变现、还是时间？」
   - 「如果给你 10 小时/周，你会怎么分配？」

3. **时间策略**
   - 「主业给你的最大价值是什么？是收入、人脉、还是安全感？」
   - 「副业什么时候可以替代主业收入？」

4. **风险控制**
   - 「如果副业失败，你的 Plan B 是什么？」
   - 「你能承受多长时间没有副业收入？」

### 参照系推荐

进入越狱模式后，将「副业主副」作为默认推荐参照系，即使其他参照系也匹配。

**推荐话术：**
> 「我注意到你已经在做 XXX 了，这说明你不是在空想，而是在行动。我建议我们从「副业主副」这个视角来分析，帮你看看从兴趣到产品，你卡在哪一步。」

## 越狱模式报告模块

在报告中增加以下部分：

### 1. 越狱信号识别
> 「你在对话中提到了已经在做 XXX，这说明你已经开始了自我救赎的旅程。这不是空想，而是行动。」

### 2. 副业变现模型
| 维度 | 当前状态 | 目标状态 | 卡点 |
|------|---------|---------|------|
| 能力提升 | | | |
| 用户/粉丝 | | | |
| 变现能力 | | | |
| 时间投入 | | | |

### 3. 时间策略建议
- 保守策略：主业 80% + 副业 20%
- 平衡策略：主业 60% + 副业 40%
- 激进策略：主业 40% + 副业 60%（需满足一定条件）

## 越狱模式注意事项

1. **不要评判副业选择**：无论用户做什么，先理解动机
2. **关注能力和资源**：不是所有副业都能变现，帮助识别可迁移能力
3. **风险意识**：提醒用户主业的安全网价值
4. **行动导向**：给出具体的下一步行动建议

## 越狱模式 vs 常规模式的切换

如果用户在越狱模式对话中表示：
- 「其实我也不想做了」→ 回到常规模式
- 「我想把副业当主业」→ 切换到「创业」参照系
- 「我就是想玩玩」→ 降低副业诊断权重，回到常规职业选择
