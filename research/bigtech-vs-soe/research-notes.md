### 1.2 国企/央企薪资

| 类型 | 年到手 | 说明 |
|---|---|---|
| 央企总部（北京） | 15-25万 | 含年终奖，信息技术部略低 |
| 央企省级分公司 | 10-18万 | 因地区差异大 |

| 市属国企 | 6-12万 | 一线城市较高 |

**关键差异：**
- 国企起薪低，但隐性福利高（公积金按最高比例、住房补贴、医疗等）
- 国企薪资增长平缓，论资排辈
- 大厂薪资增长快，但波动大

## 三、稳定性与裁员

### 3.1 互联网大厂

| 维度 | 数据 |
|---|---|
| 校招通过率 | 5%-8%（字节2026届） |
| 社招通过率 | 3%-5%（核心技术岗） |
| 裁员频率 | 高，业务调整频繁 |
| 35岁危机 | 真实存在，P7升P8困难 |

## 四、晋升机制

### 4.1 互联网大厂

| 维度 | 数据 |
|---|---|
| 晋升频率 | 每年1-2次评审 |
| P6→P7 | 2-4年（优秀者） |
| P7→P8 | 3-6年（困难，"鬼门关"） |
| P8→P9 | 极难，需要业务突破 |
| 薪资增长 | 优秀者每年涨薪20%-25% |

**关键洞察：**
- 大厂晋升不是"熬年限"，而是"看业绩+看业务"
- P7是大多数人的天花板
- 晋升名额向AI相关部门倾斜，传统业务线更难

### 4.2 国企/央企

| 维度 | 数据 |
|---|---|
| 晋升频率 | 按年限和空缺 |
| 科员→副科 | 3-5年（平均） |
| 副科→正科 | 3-5年 |
| 正科→副处 | 4-6年 |
| 薪资增长 | 每年5%-10%（普调） |

**关键洞察：**
- 国企晋升是"熬年限+人情练达"
- 晋升通道透明但缓慢
- 人际关系在晋升中权重很高

## 五、隐性成本

### 5.1 互联网大厂

| 成本类型 | 具体表现 |
|---|---|
| 健康成本 | 高强度工作导致身体透支 |
| 心理成本 | 末位淘汰、绩效焦虑 |
| 机会成本 | 技能单一化，离开平台后价值下降 |
| 家庭成本 | 996导致家庭时间极少 |
| 35岁危机 | 晋升困难，面临被优化风险 |

### 5.2 国企/央企

| 成本类型 | 具体表现 |
|---|---|
| 大脑被格式化 | 大量工作不是解决问题，而是证明流程没问题 |
| 情绪劳动 | 揣摩意图、维护关系、审时度势 |
| 技能退化 | 技能越单一，市场认知越落后 |
| 丧失纠错能力 | 3年后想跳，简历上能写的东西外面不认 |
| 社交隔离 | 同学早跑了好几圈，你还在原地等晋升 |

## 六、关键趋势

### 6.1 互联网行业趋势

1. **职级改革**：字节2025年12月完成职级改革，薪酬与职级解耦，"不升职也能涨薪"
2. **校招扩招**：腾讯宣布三年内新增2.8万个实习岗位
3. **AI倾斜**：晋升名额向AI相关部门倾斜，传统业务线P7升P8更难
4. **HC收紧**：腾讯2025年Q2全面关闭HC，其他大厂跟进
5. **薪资分化**：算法岗薪资持续走高，开发岗增长放缓

### 6.2 国企/央企趋势

1. **信息化投入加大**：央企数字化转型，信息技术部地位提升
2. **薪酬改革**：部分央企开始市场化薪酬改革
3. **年轻化趋势**：干部年轻化，35岁以下干部比例提高
4. **混合所有制**：部分国企引入市场化机制
