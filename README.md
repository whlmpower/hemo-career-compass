# hemo-career-compass

职业罗盘。通过「多参照系」进行通用职业自我认知诊断，帮助用户深度挖掘内心，完成对未来生活期望的梳理，看清自己到底想要什么。

## 安装

```bash
git clone https://github.com/whlmpower/hemo-career-compass.git
cp -r hemo-career-compass ~/.agent/skills/   # macOS/Linux
# Windows PowerShell: Copy-Item -Recurse -Force .\hemo-career-compass "$env:USERPROFILE\.agent\skills\" -Recurse
# 或复制到 %userprofile%\.agent\skills\  # Windows
```

也可通过生态工具安装：

```bash
npx skills add whlmpower/hemo-career-compass
```

或让 AI Agent 自动安装：

```
直接在对话框，输入帮我安装 https://github.com/whlmpower/hemo-career-compass
```

## 使用

安装完成后，在 AI Agent 中输入触发词即可：

### 职业方向选择
- 「大厂和国企怎么选」
- 「考公还是去企业」
- 「要不要创业」
- 「外企怎么样」
- 「体制内适合我吗」
- 「互联网加班我能不能接受」

### 教育路径选择
- 「考研还是就业」
- 「考研还是考公」
- 「要不要读研」
- 「全日制还是非全日制」
- 「国内读研还是留学」
- 「先就业还是先考研」
- 「在职考研」
- 「学历焦虑」「学历贬值」

### 副业与自我突破
- 「工作稳定但缺乏成长」
- 「体制内被困」
- 「想搞副业」
- 「自媒体」「副业」「变现」「个人IP」
- 「不想换工作但想做点别的」

### 通用职业困惑
- 「我该怎么选工作」
- 「毕业后该去哪里」
- 「我适合做什么工作」
- 「职业规划怎么弄」
- 「我想转行但不知道做什么」
- 「工作几年了很迷茫」
- 「我职业选择很迷茫」

如果 AI 以「职业罗盘」身份回应，说明安装成功。

## 核心设计理念

**不替用户做选择，而是帮他照见自己。**

传统职业咨询的问题是：顾问给出建议，用户被动接受。本 Skill 的假设是：用户内心已经有答案，只是被噪音掩盖了。AI 的角色是一面犀利、直接、不回避矛盾的镜子。

### 关键特性

| 特性 | 说明 |
|---|---|
| **越狱信号识别** | 自动识别用户已在"自我救赎"的状态（如搞副业、自媒体、AI项目），诊断焦点从"选哪个"转向"卡在哪" |
| **数据驱动诊断** | 每个参照系都有权威数据支撑（薪资、报录比、存活率等），不说"我觉得"，说"数据显示" |
| **家庭锚点** | 专门诊断伴侣/父母/家庭责任对职业选择的影响，这是中国用户决策的核心变量 |
| **自适应轮次** | 根据用户回答深度动态决定对话轮次，浅的少问，深的多问 |

### 关键设计决策

| 决策点 | 选择 | 理由 |
|---|---|---|
| 用户画像 | 面向所有面临职业选择的年轻人 | 不仅限于应届生，也适合工作几年后重新选择的人群 |
| 交付形式 | 对话式问卷 | 深度挖掘需要多轮对话，表单无法承载 |
| 心理学视角 | 混合多模型 | 大五做表层，职业锚/价值观/依恋做深层交叉验证 |
| AI 角色 | 诊断师 | 对话中实时分析并追问，而非事后出报告 |
| 输出边界 | 自我认知深化优先 | 核心目标是帮用户看清自己，职业建议是副产品 |
| 对话轮次 | 自适应 | 根据用户回答深度动态决定，浅的少问，深的多问 |
| 犀利度 | 犀利 | 用户需要被挑战，而非被安抚 |
| 参照系 | 多参照系可扩展 | 6个参照系覆盖职业/教育/副业场景，用户可随时切换 |
| 事实依据 | 数据驱动 | 每个参照系配备研究笔记，33+权威数据来源 |

## 平台兼容性

本 Skill 采用标准格式设计，可在以下平台运行：
- Trae Code
- WorkBuddy
- 千问办公
- Codex
- 其他支持 Skill 标准的 AI Agent

### 兼容性要求

1. **文件读取**：Agent 需要能够读取本地文件系统（`prompts/`、`frameworks/`、`references/` 目录）
2. **多轮对话**：Agent 需要支持上下文保持，能够跨轮次引用之前的对话内容
3. **文件写入**：如果需要支持多 Session，Agent 需要能够写入会话摘要文件
