# 风险容忍度诊断框架

本文件定义「职业罗盘」中使用的风险容忍度（Risk Tolerance）诊断逻辑。

## 概述

风险容忍度是个人对不确定性和损失的承受能力。在职业选择中，它直接决定用户能承受多大的波动来换取多大的回报。

风险容忍度 = 对不确定性的承受能力 + 对损失的承受能力

## 维度定义与诊断逻辑

### 对不确定性的承受能力

**高容忍信号：**
- 用户对「未来不确定」有正面反应：「我喜欢未知」「变化让我兴奋」
- 用户有创业、跳槽、转行的经历
- 用户愿意为「可能性」牺牲「确定性」
- 用户对「Plan B」不太在意

**低容忍信号：**
- 用户对「未来不确定」有负面反应：「我不知道未来会怎样，这让我焦虑」
- 用户偏好稳定、可预测的工作
- 用户需要详细的职业规划和时间线
- 用户对「Plan B」有强烈需求

### 对损失的承受能力

**高容忍信号：**
- 用户对「试错成本」不太在意：「大不了重来」
- 用户有投资、创业、高风险决策的经历
- 用户能承受财务波动
- 用户不介意「沉没成本」

**低容忍信号：**
- 用户对「损失」有强烈恐惧：「我输不起」
- 用户有强烈的储蓄倾向
- 用户决策时优先考虑「最坏情况」
- 用户对「沉没成本」敏感

## 对话策略

### 触发问题

**不要直接问：** 「你的风险容忍度高吗？」

**要问：**
- 「描述一次你承担风险的经历。当时发生了什么？你做了什么？结果如何？」
- 「如果明天你被裁了，你的 Plan B 是什么？」
- 「你愿意为了更高的收入承受多大的不确定性？」
- 「你父母对你的职业选择有什么期待？你会在意吗？」
- 「想象一下，你工作五年后，如果行业发生了巨大变化，你会怎么做？」

### 案例优先

- 用户说「我风险承受能力还可以」→ 「描述一次你承担风险的经历，当时发生了什么？你做了什么？结果如何？」
- 用户说「我怕失业」→ 「如果明天你被裁了，最坏的结果是什么？你想象过吗？」

### 盲区识别

- 用户声称「我能承受风险」但没有实际经历 → 可能过度自信
- 用户声称「我求稳」但多次跳槽/转行 → 可能用「求稳」掩盖其他需求
- 用户声称「我不在乎钱」但对薪资差距敏感 → 可能低估了财务风险

## 评分参考

| 风险容忍度 | 大厂适配 | 国企适配 |
|---|---|---|
| 高 | ★★★★★ | ★★☆☆☆ |
| 中 | ★★★★☆ | ★★★★☆ |
| 低 | ★★☆☆☆ | ★★★★★ |

**注意：**
- 风险容忍度不是固定特质，会随年龄、财富、家庭责任变化
- 应届生通常风险容忍度较高，但随着年龄增长会下降
- 要关注用户当前的**实际**风险容忍度，而不是他**认为**自己应该有的

## 与其他维度的交叉

- **风险容忍度 + 神经质**：高神经质 + 低风险容忍 → 强烈倾向国企；低神经质 + 高风险容忍 → 强烈倾向大厂
- **风险容忍度 + 职业锚**：高安全型锚 + 低风险容忍 → 国企；高创造型锚 + 高风险容忍 → 创业
- **风险容忍度 + 价值观**：高安全导向 + 低风险容忍 → 国企；高刺激/成就导向 + 高风险容忍 → 大厂

## 特殊考量：家庭背景的影响

风险容忍度不是孤立的，家庭背景是重要的调节变量：

| 家庭背景 | 对风险容忍度的影响 | 诊断要点 |
|---|---|---|
| 家庭经济条件好，有退路 | 实际风险容忍度可能高于自我感知 | 询问：「如果最坏情况发生，你的家庭能给你什么支持？」 |
| 家庭经济条件一般，需要反哺 | 实际风险容忍度可能低于自我感知 | 询问：「你每月需要给家里寄钱吗？如果失业，对你的家庭有什么影响？」 |
| 家庭有资源（如房产、人脉） | 可能更需要「自主性」而非「安全」 | 询问：「你家里有没有什么资源是你觉得自己可以利用的？」 |
| 家庭期望高（如「光宗耀祖」） | 可能用「稳定」换取「安全感」，但内心渴望成就 | 询问：「你父母对你的职业有什么期待？你会在意吗？」 |

## 出路难度与风险的关系

当用户询问出路时，风险容忍度是核心判断依据：

| 出路 | 风险等级 | 适合的风险容忍度 | 关键条件 |
|---|---|---|---|
| 大厂跳槽 | 中 | 中-高 | 持续保持竞争力和人脉 |
| 中小厂降维打击 | 中-高 | 高 | 快速适应能力、核心技能 |
| 单干/创业 | 极高 | 极高 | 资源、能力、运气的结合 |
| 同一家单位深耕 | 低 | 低 | 耐得住寂寞、组织有晋升通道 |
| 考公考编 | 低 | 低-中 | 考试能力、运气 |
| 跳去民企/乙方 | 高 | 高 | 必须带走资源，否则价值大打折扣 |
| 副业主副 | 中 | 中-高 | 主业时间允许、副业有成熟模式 |
