# 家庭锚点诊断框架

本文件定义「职业罗盘」中使用的家庭锚点（Family Anchor）诊断逻辑。

## 概述

家庭锚点是指个人在职业决策中，受家庭/伴侣影响的程度和方式。它不是简单的「父母支持/不支持」，而是**你的职业选择在多大程度上是为了「让家人安心」**。

在职业选择诊断中，家庭锚点往往是一个**隐性变量**——用户可能意识不到它在影响决策，但它的影响无处不在。

## 维度定义与诊断逻辑

### 1. 伴侣影响度

**核心问题：** 你的职业选择在多大程度上受到伴侣的影响？

**信号：**
- 用户提到「我对象觉得…」「我女朋友/男朋友说…」
- 用户描述职业决策时，会先考虑「TA会怎么想」
- 用户提到「为了家庭」「为了孩子」「为了让TA安心」
- 用户对伴侣的职业选择有明确态度

**影响度分级：**
- **高影响**：职业决策前必须和伴侣商量，伴侣反对的事基本不会做
- **中影响**：会考虑伴侣意见，但最终自己决定
- **低影响**：职业决策基本独立，伴侣意见仅供参考

**诊断逻辑：**
- 高影响 + 伴侣支持 → 决策阻力小，但需要持续维护伴侣认同
- 高影响 + 伴侣反对 → 决策阻力大，可能产生长期矛盾
- 低影响 → 需要评估：是真的独立，还是伴侣在「让着你」

### 2. 父母期待内化度

**核心问题：** 你多大程度上把父母的期待当成了自己的目标？

**信号：**
- 用户提到「我父母希望我…」「我爸说…」「我妈觉得…」
- 用户在描述职业目标时，会使用「应该」「必须」等词汇
- 用户提到「让父母安心」「不让父母担心」
- 用户对「稳定」「体面」有强烈追求，但说不清为什么

**内化度分级：**
- **高内化**：父母的期待已经变成自己的价值观，决策时不会觉得是「外部压力」
- **中内化**：能区分「父母的期待」和「自己的渴望」，但会有意无意地妥协
- **低内化**：清楚地知道「那是父母的渴望，不是我的」，但可能有愧疚感

**诊断逻辑：**
- 高内化 + 父母期待与自我渴望一致 → 和谐，但需要警惕「这只是父母的梦想，不是你的」
- 高内化 + 父母期待与自我渴望冲突 → 内心拉扯严重，需要「分离」工作
- 低内化 → 相对自由，但可能有「背叛感」

### 3. 家庭责任优先级

**核心问题：** 在「个人成长」和「家庭责任」之间，你的优先级是什么？

**信号：**
- 用户提到「我不能冒险」「我需要稳定收入」
- 用户提到「陪伴伴侣」「陪孩子」「照顾父母」
- 用户描述职业选择时，会权衡「时间投入」和「家庭影响」
- 用户对「工作生活平衡」有明确要求

**优先级分级：**
- **家庭优先**：任何可能影响家庭的职业选择都会被排除
- **平衡型**：希望在个人成长和家庭责任之间找到平衡点
- **自我优先**：个人成长和实现优先于家庭需求

**诊断逻辑：**
- 家庭优先 → 不适合高风险、高时间投入的路径（如创业、大厂）
- 平衡型 → 适合副业主副等可控路径
- 自我优先 → 需要评估：是真的自我优先，还是尚未承担家庭责任

### 4. 经济依赖度

**核心问题：** 你的职业选择在多大程度上受到经济因素的约束？

**信号：**
- 用户提到「收入不能降」「我需要养家」
- 用户提到「房贷」「车贷」「孩子教育费」
- 用户对收入稳定性有极高要求
- 用户提到「我需要攒钱」「我不能乱花钱」

**依赖度分级：**
- **高依赖**：收入必须覆盖家庭所有开支，几乎没有容错空间
- **中依赖**：收入是家庭主要来源，但有一定储蓄缓冲
- **低依赖**：家庭有多个收入来源，或经济压力较小

**诊断逻辑：**
- 高依赖 → 风险容忍度天然低，不适合裸辞、创业等高风险路径
- 中依赖 → 可以承受一定风险，但需要明确的止损线
- 低依赖 → 风险容忍度可能被低估，需要探索「真正想要什么」

## 对话策略

### 触发问题

**不要直接问：** 「你父母对你职业选择有什么影响？」

**要问：**
- 「你的伴侣对你的职业选择有什么看法？」
- 「如果做一个决定需要伴侣支持，你觉得她会说什么？」
- 「父母对你的职业有什么期待？你在意吗？」
- 「你的职业选择，多大程度上是为了『让家人安心』？」

### 案例优先

- 用户说「我父母希望我稳定」→ 「描述一次你和父母讨论职业选择的经历。当时发生了什么？你做了什么决定？结果如何？」
- 用户说「我对象支持我」→ 「上次你做职业决策时，你是怎么和伴侣商量的？她给了什么反馈？你采纳了吗？」

### 盲区识别

- 用户声称「我伴侣很支持我」但描述中充满矛盾 → 可能伴侣的支持有条件，或用户选择性听到了支持
- 用户声称「我不在意父母想法」但决策完全符合父母期待 → 可能内化度高，但意识不到
- 用户声称「家庭责任很重要」但从未和伴侣深入讨论过职业规划 → 可能只是口头说说，没有真正的家庭共识

## 与其他维度的交叉

- **家庭锚点 + 风险容忍度**：高家庭责任 + 高经济依赖 → 风险容忍度被强力约束
- **家庭锚点 + 职业锚**：高伴侣影响 + 安全/稳定型锚 → 极度倾向稳定路径
- **家庭锚点 + 价值观**：高父母期待内化 + 传统价值观 → 可能压抑自我实现需求
- **家庭锚点 + 依恋类型**：高伴侣影响 + 焦虑型依恋 → 可能过度寻求伴侣认可

## 评分参考

| 家庭锚点维度 | 高 | 中 | 低 |
|---|---|---|---|
| 伴侣影响度 | 决策前必须商量 | 会考虑但自己决定 | 基本独立 |
| 父母期待内化度 | 已经变成自己的价值观 | 会妥协但清醒 | 清楚界限 |
| 家庭责任优先级 | 家庭优先 | 平衡型 | 自我优先 |
| 经济依赖度 | 必须覆盖家庭开支 | 主要来源有缓冲 | 多来源或压力小 |

## 使用指南

1. **不要生硬追问**：家庭话题可能敏感，要根据用户开放度调节追问深度
2. **观察回避信号**：如果用户对家庭话题明显回避，不要强行追问
3. **区分「事实」和「感受」**：用户说「我伴侣支持我」是事实，「我觉得她支持我」是感受，两者可能不一致
4. **关注「隐性约束」**：家庭锚点往往是隐性约束，用户可能意识不到它在影响决策
