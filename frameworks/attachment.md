# 依恋类型诊断框架

本文件定义「职业罗盘」中使用的依恋类型（Attachment Theory）诊断逻辑。

## 概述

依恋理论最初由约翰·鲍尔比（John Bowlby）提出，用于解释婴儿与照顾者之间的情感纽带。后来被扩展到成人关系领域，特别是亲密关系和职场关系。

在职业选择诊断中，我们使用依恋类型来理解用户与**组织、权威、规则**的关系模式。

三种依恋类型：
1. 安全型（Secure）
2. 焦虑型（Anxious）
3. 回避型（Avoidant）

## 维度定义与诊断逻辑

### 安全型（Secure）

**核心特征：** 对亲密关系 comfortable，既不过度依赖也不过度疏离。在职场中表现为：能与领导建立良好关系，既不完全讨好也不完全对抗，在集体中感到舒适。

**信号：**
- 用户描述与领导/老师的关系「还不错」「正常」
- 用户能在团队中自如地表达观点
- 用户对「人情世故」不排斥也不热衷
- 用户在描述冲突时能保持客观

**与职业选择的关联：**
- 安全型两者皆可，但需要注意：
  - 大厂：安全型通常适应良好，但可能缺乏深度连接
  - 国企：安全型需要额外注意「人情练达」，因为国企的关系密度更高

### 焦虑型（Anxious）

**核心特征：** 渴望亲密但害怕被抛弃，需要不断确认关系。在职场中表现为：过度在意领导评价、害怕被排斥、需要通过他人认可确认自我价值。

**信号：**
- 用户提到「我很在意领导的看法」
- 用户描述自己「容易想太多」「别人一句话我会琢磨很久」
- 用户对「被边缘化」「被孤立」有强烈恐惧
- 用户在团队中努力讨好他人

**与职业选择的关联：**
- 焦虑型 → 需要谨慎评估：
  - 大厂：快节奏、结果导向，可能加剧焦虑。反馈直接，但也可能带来反复的情绪波动
  - 国企：稳定结构可能提供安抚，但「揣摩上意」「情绪劳动」可能加重焦虑负担
  - 建议：无论选择哪条路，都需要建立「内在评价体系」，减少对外部认可的依赖

### 回避型（Avoidant）

**核心特征：** 对亲密关系不舒服，强调独立和自主。在职场中表现为：不喜欢依赖别人、不喜欢被管理、对「人情世故」有排斥、倾向于用实力说话。

**信号：**
- 用户提到「我不喜欢搞关系」「我只想把事做好」
- 用户对「揣摩上意」「饭局文化」有强烈排斥
- 用户描述自己「独来独往」「不喜欢团队」
- 用户对「人情社会」有负面评价

**与职业选择的关联：**
- 回避型 → 强烈倾向大厂：
  - 大厂：相对扁平，规则相对透明，可以用实力说话
  - 国企：层级分明、人情密度高，回避型容易感到窒息
  - 如果用户是回避型但选择国企，需要评估：他是否有能力/意愿发展必要的人际技能？

## 对话策略

### 触发问题

**不要直接问：** 「你的依恋类型是什么？」

**要问：**
- 「描述一次你和领导/权威人物的互动经历。当时发生了什么？你做了什么？结果如何？」
- 「如果公司要求你做一件你认为没意义的事，你会怎么做？」
- 「你擅长『揣摩上意』吗？这种能力对你来说是天赋还是负担？」
- 「描述一次你被团队排斥或边缘化的经历。当时发生了什么？你做了什么？结果如何？」

### 案例优先

- 用户说「我不喜欢搞关系」→ 「上次你需要『搞关系』是在什么时候？具体发生了什么？你做了什么？结果如何？」
- 用户说「我很在意领导看法」→ 「描述一次你因为领导的一句话而焦虑的经历。那句话是什么？你琢磨了多久？最后你怎么处理的？」

### 盲区识别

- 用户声称「我不在乎别人评价」但对负面反馈反应强烈 → 可能回避型 + 高自尊
- 用户声称「我人际关系很好」但描述中充满被排斥经历 → 可能焦虑型 + 讨好模式
- 用户声称「我擅长人情世故」但对「揣摩上意」有厌恶感 → 可能安全型 + 价值观冲突

## 评分参考

| 依恋类型 | 大厂适配 | 国企适配 | 关键注意事项 |
|---|---|---|---|
| 安全型 | ★★★★☆ | ★★★★☆ | 国企需要额外注意人情练达 |
| 焦虑型 | ★★★☆☆ | ★★★☆☆ | 都需要建立内在评价体系 |
| 回避型 | ★★★★★ | ★★☆☆☆ | 国企可能让人窒息 |

**注意：** 依恋类型不是固定的，会随经历变化。诊断时要关注当前状态，而不是标签化。

## 与其他维度的交叉

- **依恋类型 + 职业锚**：回避型 + 自主/独立型 → 不适合国企；安全型 + 管理型 → 两者皆可
- **依恋类型 + 价值观**：焦虑型 + 权力/成就导向 → 需要警惕「讨好式成功」；回避型 + 自我导向 → 不适合需要大量人际互动的岗位
- **依恋类型 + 风险容忍度**：焦虑型 + 低风险容忍 → 国企的稳定可能提供安抚，但人情消耗可能加重焦虑；回避型 + 高风险容忍 → 大厂或创业
