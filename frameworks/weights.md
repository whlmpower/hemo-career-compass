# 动态权重矩阵

本文件定义了不同参照系下，各诊断维度的权重。AI 在综合诊断阶段，根据用户选择的参照系，应用对应的权重计算加权得分。

## 使用方式

当用户选择了某个参照系后，AI 读取该参照系的 `meta.json` 中的 `weights` 字段，按照权重计算各维度的加权得分。

**计算公式：**
```
加权得分 = Σ(维度得分 × 维度权重) / Σ(权重)
```

**示例：**
如果用户在「创业」参照系下：
- 成就驱动力得分 90，权重 95
- 安全需求得分 40，权重 20
- 自主性需求得分 85，权重 100

加权得分 = (90×95 + 40×20 + 85×100 + ...) / (95 + 20 + 100 + ...)

## 权重使用规则

1. **不直接告诉用户权重**：权重是 AI 内部的判断依据，不直接展示给用户
2. **权重用于加权计算**：在综合诊断阶段，应用权重计算各维度的加权得分
3. **权重仅供参考**：权重是参考值，不是绝对标准。AI 需要根据用户的具体情况灵活调整
4. **权重可扩展**：新增参照系时，在 `meta.json` 中定义权重即可
