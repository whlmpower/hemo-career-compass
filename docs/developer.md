# 开发者详细说明

本文档提供 `hemo-career-compass` 的详细开发说明、架构设计和扩展指南。


## 核心设计原则

### 1. 不替用户做选择

这是本 Skill 的根基。AI 的 role 是镜子，不是顾问。

**实现方式：**
- 系统提示词中明确禁止给出「你适合 X」的结论
- 所有输出都使用「我注意到…」「你提到…」的观察性语言
- 报告模板中不包含「建议」部分，只有「下一步探索方向」

### 2. 案例优先

抽象回答没有诊断价值。

**实现方式：**
- `socratic.md` 中定义了「案例优先」策略
- 每个诊断框架都包含「不要直接问」和「要问」的对比
- 系统提示词中强调：如果用户给出抽象回答，必须追问具体案例

### 3. 犀利但慈悲

应届生需要被挑战，而非被安抚。

**实现方式：**
- `socratic.md` 中定义了「犀利度动态调节」机制
- 系统提示词中定义了「温和模式」和「犀利模式」的切换条件
- 金句库中的洞察用于点醒，不是说教

### 4. 自适应轮次

不固定问题数量，根据用户回答深度动态决定。

**实现方式：**
- 系统提示词中定义了状态机：
  - 状态0：暖启动
  - 状态1：基础信息采集（必须完成）
  - 状态2：深层诊断（自适应展开）
  - 状态3：综合诊断
  - 状态4：报告确认
- 每个状态的转换条件都明确定义

## 文件引用约定

### Skill 根目录

所有相对路径都基于 Skill 根目录：`.trae/skills/hemo-career-compass/`

### 文件引用示例

在 `system.md` 中引用其他文件时，使用以下格式：

```
详见 `prompts/report.md`
详见 `references/insights.md`
详见 `frameworks/bigfive.md`
```

**注意：** 不要使用 `./prompts/report.md` 或绝对路径。Skill 加载器会自动基于 Skill 根目录解析这些路径。

## 多 Session 支持

### 会话摘要格式

当用户中途退出时，AI 应生成以下格式的会话摘要：

```json
{
  "skill": "hemo-career-compass",
  "version": "1.0.0",
  "session_date": "2026-08-09",
  "user_profile": {
    "family_background": "...",
    "education": "...",
    "consumption_habits": "...",
    "anxieties": ["...", "...", "..."]
  },
  "diagnosed_dimensions": [
    {
      "dimension": "职业锚",
      "type": "管理型（事权）",
      "confidence": "高",
      "key_evidence": ["...", "..."]
    }
  ],
  "pending_dimensions": [
    "依恋类型",
    "风险容忍度"
  ],
  "key_findings": [
    "...",
    "..."
  ],
  "next_session_plan": "建议从依恋类型切入，追问用户与领导/权威的互动经历"
}
```

### 会话恢复

当用户带着新案例回来时，AI 应：
1. 读取会话摘要
2. 快速回顾已采集的信息和已诊断的维度
3. 从「待探索路径」中选择最合适的切入角度
4. 避免重复询问已经充分探讨的问题

## 扩展指南

### 添加新的诊断维度

1. 在 `frameworks/` 目录下创建新的 `.md` 文件
2. 在 `system.md` 的「深层诊断维度」部分添加新维度的定义
3. 在 `system.md` 的「雷达图维度」部分添加新维度（如果需要）
4. 在 `report.md` 的「雷达图」部分添加新维度的报告模板

### 添加新的提问策略

1. 在 `socratic.md` 中添加新的策略章节
2. 在 `system.md` 的「苏格拉底式提问」表格中添加新策略
3. 在 `system.md` 的「犀利度动态调节」部分更新相关规则

### 添加新的金句

1. 在 `references/insights.md` 的「金句库」部分添加新金句
2. 标注适用场景和引用方式
3. 在 `system.md` 的「金句库」部分更新使用原则

## 测试清单

在发布新版本前，请确认以下测试用例通过：

- [ ] 暖启动话术自然，能建立信任
- [ ] 基础信息采集完整覆盖 5 个维度
- [ ] 深层诊断能根据用户回答自适应展开
- [ ] 苏格拉底式提问能有效挖掘深层信息
- [ ] 报告输出前有确认步骤
- [ ] 报告结构完整（6 个部分）
- [ ] 金句引用自然，不生硬
- [ ] 犀利度调节灵敏（用户防御强时降级，开放度高时升级）
- [ ] 多 Session 会话摘要格式正确
- [ ] 文件引用路径正确

## 已知限制

1. **多平台路径差异**：不同平台的 Skill 加载器对相对路径的处理可能不同，需要在实际平台上测试
2. **上下文长度限制**：如果对话轮次过多，可能超出 AI 的上下文窗口，需要实现摘要压缩机制
3. **心理学模型的简化**：本 Skill 对心理学模型进行了简化，不能替代专业的心理咨询
